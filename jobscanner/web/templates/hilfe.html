In 5 Minuten mit Bob verbunden

Diese Anleitung führt dich Schritt für Schritt: vom Konto bis zum ersten eigenen Scan. Die ersten beiden Schritte laufen komplett im Browser — danach verbindest du optional dein eigenes Claude und suchst selbst neue Jobs.

Los geht's ↓

So machst du mit

1. Registrieren — mit dem Invite-Code aus Discord ein Konto anlegen.

2. Profil anlegen — Skills, Zielrollen und Wünsche eintragen; ab da bewerte ich den Job-Pool automatisch für dich, ganz ohne Installation.

3. Optional: eigenes Claude-Abo anbinden — Claude Code installieren, API-Token holen, Bob-Plugin verbinden.

4. Loslegen mit /bob:bob-scan — gratis über deine Heim-IP neue Jobs suchen, ganz ohne Keys.

Profil erstellen →

Bevor du startest

  • Den Invite-Code aus dem Discord-Post. Damit legst du in Schritt 1 deinen Account an.
  • Für den optionalen Claude-Teil (ab Schritt 3): ein Claude-Abo. Claude Pro reicht. Ohne Abo funktioniert die Website trotzdem — Bob bewertet den Job-Pool auch so für dich.

⏱ Schritte 1–2: ca. 2 Minuten · komplett mit Claude: ca. 5–10 Minuten.

1

Account bei Bob anlegen

Öffne die Registrierung und trage Benutzername, Email, ein Passwort und den Invite-Code aus Discord ein — Einwilligung ankreuzen, fertig.

→ Zur Registrierung

💡 Nach dem Klick auf „Konto anlegen" bist du direkt eingeloggt und landest auf deiner Startseite.

2

Profil anlegen

Der Profil-Wizard fragt Skills, Zielrollen und Wünsche ab. Sobald dein Profil steht, bewertet Bob den gemeinsamen Job-Pool automatisch für dich — die ersten Treffer erscheinen in deinem Dashboard, ohne dass du irgendetwas installieren musst.

→ Profil-Wizard starten

3

Claude Code installieren

Ab hier beginnt der optionale Teil mit deinem eigenen Claude-Abo — fürs Scannen und die LLM-Bewertung.

Claude Code ist das Terminal-Programm, in dem Bob als Plugin läuft. Öffne dein Terminal und führe einen der Befehle aus — je nach Betriebssystem.

Windows · PowerShell
irm https://claude.ai/install.ps1 | iex
macOS / Linux · Terminal
curl -fsSL https://claude.ai/install.sh | bash

💡 Nach der Installation einmal claude eingeben und dich mit deinem Claude-Abo anmelden — Claude Code führt dich dabei durch den Login.

4

API-Token holen

Das Token verbindet dein Claude mit Bob. Öffne in der Sidebar ⚙ Einstellungen → Reiter „API-Token" → „API-Token erzeugen".

⚠️ Sofort kopieren! Das Token wird nur ein einziges Mal angezeigt. Verloren? Kein Problem — erzeuge einfach ein neues; das alte wird dabei ungültig.

5

Bob mit deinem Claude verbinden

Starte claude und gib die beiden Befehle nacheinander ein. Der erste fügt Bobs Plugin-Quelle hinzu, der zweite installiert das Plugin.

in Claude Code
/plugin marketplace add DJTJ9/bob-member-kit
in Claude Code
/plugin install bob@bob-kit

Beim Installieren fragt Claude nach deinem API-Token (aus Schritt 4) — einfügen, fertig. Die Felder für Adzuna- und Jooble-Keys kannst du leer lassen; die braucht nur die optionale eigene Suche.

💡 Nach dem Installieren Claude einmal neu starten, damit das Plugin geladen wird.

6

Loslegen: dein erster Scan

Jetzt kannst du selbst neue Jobs suchen — gratis über deine Heim-IP, ganz ohne Keys:

in Claude Code
/bob:bob-scan

Bob fragt nach der Scan-Größe, durchsucht StepStone & Indeed über deine Heim-IP und liefert die Treffer in den gemeinsamen Pool. Frische Funde werden sofort gegen dein Profil bewertet — die Ergebnisse erscheinen in deinem Dashboard.

↻

Wie es weitergeht

Bewerte Treffer im Dashboard mit 👍/👎. Mit /bob:bob-learn destilliert Bob daraus deine persönlichen Kriterien — und schaltet damit /bob:bob-rescore frei: die LLM-Neubewertung deiner besten Treffer über dein Claude-Abo (Tier mittel/hoch).

Mehr Portale (optional): Mit kostenlosen Keys von Adzuna und Jooble nimmt dein Scan zwei zusätzliche Portale mit.

→ Mehr Portale: Adzuna- & Jooble-Keys (optional)

🛰Scan-Anleitung Heim-IP-Scan einrichten 🔑API-Keys holen Adzuna/Jooble Schritt für Schritt 🔍Scan starten Befehle + letzter Scan-Stand

Wie Bob und dein Claude zusammenarbeiten

Damit du weißt, was passiert: dein Claude spricht über eine verschlüsselte Verbindung mit dem Bob-Server. Job-Rohtexte und deine Kriterien kommen zu dir, Bewertungen gehen zurück.

🔒 Dein Token authentifiziert jede Verbindung. Deine Bewertungen sind privat — andere Member sehen sie nicht.

🔒

Sicherheit — kurz & ehrlich

  • Dein API-Token ist persönlich. Nicht teilen, nicht in Code committen. Claude legt es sicher ab (Schlüsselbund bzw. Credentials-Datei), nicht in einem öffentlichen Repo.
  • Adzuna-/Jooble-Keys liegen im Klartext in deiner ~/.claude/settings.json — ein bewusster Kompromiss, damit die eigene Suche funktioniert. Es sind kostenlose Keys ohne Zugriff auf Bob-Daten; leg dort nichts Wertvolleres ab.
  • Alles ist einsehbar. Das komplette Plugin ist öffentlich lesbar: bob-member-kit ↗.
✓

Geschafft? So sieht Erfolg aus

  • ✅ /plugin install bob@bob-kit lief durch und fragte nach deinem Token.
  • ✅ /bob:bob-scan startet ohne „401" und läuft durch.
  • ✅ In deinem Dashboard erscheinen neue, bewertete Jobs.

Wenn alle drei Haken sitzen, bist du fertig — und jeder Scan, den du fährst, macht die Treffer für alle Member besser. 🚀

Scannen & Befehle

/bob:bob-rescore vs. /bob:bob-scan?

bob-rescore bewertet gute Treffer nach dem Lernen mit dem LLM neu (Tier mittel/hoch). bob-scan findet neue Jobs über deine Heim-IP und bewertet sie sofort deterministisch (gratis, keine Keys). Scan-Anleitung · Mehr →

Brauche ich Keys für /bob:bob-scan?

Nein — der Standard-Scan läuft ohne Keys über deine Heim-IP. Adzuna und Jooble sind optionale Zusatz-Portale. Mehr Portale (optional)

Einstieg & Fehler

Fehler „401" / „Unauthorized" beim ersten Bob-Befehl

Das Token wird nicht erkannt. Erzeuge in den Einstellungen ein neues Token (Schritt 4) und trag es per /plugin in der Bob-Konfiguration neu ein. Achte darauf, das komplette Token (bob_ + lange Zeichenfolge) ohne Leerzeichen einzufügen.

Die Befehle /bob:bob-rescore / /bob:bob-scan gibt es nicht

Das Plugin ist noch nicht geladen. Beende Claude Code und starte es neu. Prüfen kannst du es mit /plugin — dort muss bob als installiert erscheinen.

„Marketplace nicht gefunden" bei Schritt 4

Tippfehler im Befehl. Er lautet exakt /plugin marketplace add DJTJ9/bob-member-kit — am besten oben den Kopier-Button benutzen.
