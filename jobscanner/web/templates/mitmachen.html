Bob sucht Jobs.
Du gibst ihm dein Claude-Abo.

Bob sammelt Stellenanzeigen und hält sie bereit. Das Bewerten übernimmt dein eigener Claude — dafür brauchst du nichts zu installieren außer Claude Code selbst. Jede Anzeige, die du bewertest, verbessert die Treffer für alle.

Code ansehen ↗ GitHub

In vier Schritten dabei

Die Reihenfolge ist echt: ohne Claude Code kein Plugin, ohne Account kein Token. Arbeite dich von oben nach unten durch.

−0 m

Claude Code installieren

PowerShell öffnen und ausführen:

irm https://claude.ai/install.ps1 | iex

Auf macOS/Linux stattdessen: curl -fsSL https://claude.ai/install.sh | bash. Du brauchst ein Claude-Abo — Pro reicht.

−10 m

Account anlegen

Den Invite-Code findest du im Discord-Post.

Registrieren →
−20 m

API-Token holen

Nach dem Einloggen auf der Startseite: „API-Token erzeugen". Kopier ihn sofort — er wird nur ein einziges Mal angezeigt.

Verloren? Einfach ein neues erzeugen; das alte wird dabei ungültig.

−30 m

Bob mit deinem Claude verbinden

claude starten und beide Befehle nacheinander eingeben:

/plugin marketplace add DJTJ9/bob-member-kit
/plugin install bob@bob-kit

Claude fragt dabei nach deinem Token. Die Adzuna-/Jooble-Keys kannst du leer lassen — die braucht nur die eigene Suche.

Fertig. /bob:bob-score bewertet ab jetzt wartende Jobs für deine Profile. /bob:bob-scan sucht mit eigenen Keys neue.

Was dein Claude dabei tut

Alles, was das Plugin anweist, ist öffentlich lesbar — bevor du dein Abo dafür hergibst, kannst du es nachlesen: bob-member-kit ↗. Bob schickt deinem Claude Job-Rohtexte und deine Kriterien; zurück kommen Extraktionen und Bewertungen. Deine Bewertungen sind deine — andere Member sehen sie nicht.

Updates ziehst du später mit /plugin marketplace update bob-kit.
