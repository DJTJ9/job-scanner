MEHR PORTALE: KOSTENLOSE JOB-KEYS

Der Standard-Scan läuft ohne Keys über deine Heim-IP. Mit eigenen Keys von Adzuna und Jooble nimmt /bob:bob-scan zusätzlich diese beiden Portale mit (optional) — beide APIs sind kostenlos.

Was sind Adzuna und Jooble?

  • Adzuna — kostenloser Job-Such-Aggregator mit freier API. Du brauchst zwei Werte: eine App ID und einen App Key.
  • Jooble — kostenloser Job-Aggregator mit freier API. Du brauchst einen einzelnen API-Key.
A

Adzuna: App ID + App Key

Konto auf developer.adzuna.com anlegen → App registrieren → App ID + App Key ablesen.

  1. Auf „Sign up" klicken und Konto anlegen.
  2. Im Dashboard eine neue Application registrieren.
  3. Application ID und Application Key notieren.
J

Jooble: API-Key

API-Key auf jooble.org/api/about beantragen → Key ablesen.

🔗 Öffne die Jooble-API-Seite direkt: jooble.org/api/about. Dort füllst du das API-Key-Formular aus und bekommst deinen persönlichen API-Key zugeschickt.

  1. Seite öffnen und das API-Key-Formular ausfüllen.
  2. Den zugeschickten API-Key notieren.

Keys eintragen

Trag die Werte per /plugin in der Bob-Konfiguration ein (Felder für Adzuna App ID, Adzuna App Key und Jooble Key). Danach nimmt /bob:bob-scan Adzuna & Jooble bei jedem Scan zusätzlich mit — ohne Keys läuft der Scan ganz normal weiter über deine Heim-IP.
