In 5 Minuten mit Bob verbunden

Diese Anleitung führt dich Schritt für Schritt: von „noch nichts installiert" bis „Bob bewertet Jobs mit deinem eigenen Claude". Kein Download, keine Server-Einrichtung — nur fünf Schritte, jeder mit Bild.

Los geht's ↓

Bevor du startest — zwei Dinge

  • Ein Claude-Abo. Claude Pro reicht. Ohne Abo kannst du Claude Code nicht nutzen.
  • Den Invite-Code aus dem Discord-Post. Damit legst du in Schritt 2 deinen Account an.

⏱ Dauer insgesamt: ca. 5–10 Minuten.

1

Claude Code installieren

Claude Code ist das Terminal-Programm, in dem Bob als Plugin läuft. Öffne dein Terminal und führe einen der Befehle aus — je nach Betriebssystem.

Windows · PowerShell
irm https://claude.ai/install.ps1 | iex
macOS / Linux · Terminal
curl -fsSL https://claude.ai/install.sh | bash

💡 Nach der Installation einmal claude eingeben und dich mit deinem Claude-Abo anmelden — Claude Code führt dich dabei durch den Login.

2

Account bei Bob anlegen

Öffne die Registrierung und trage Email, ein Passwort und den Invite-Code aus Discord ein.

→ Zur Registrierung

💡 Nach dem Klick auf „Konto anlegen" bist du direkt eingeloggt und landest auf deiner Startseite.

3

API-Token holen

Das Token verbindet später dein Claude mit Bob. Auf deiner Startseite findest du den Abschnitt „API-Token für Claude" — klick dort auf „API-Token erzeugen".

⚠️ Sofort kopieren! Das Token wird nur ein einziges Mal angezeigt. Verloren? Kein Problem — erzeuge einfach ein neues; das alte wird dabei ungültig.

4

Bob mit deinem Claude verbinden

Starte claude und gib die beiden Befehle nacheinander ein. Der erste fügt Bobs Plugin-Quelle hinzu, der zweite installiert das Plugin.

in Claude Code
/plugin marketplace add DJTJ9/bob-member-kit
in Claude Code
/plugin install bob@bob-kit

Beim Installieren fragt Claude nach deinem API-Token (aus Schritt 3) — einfügen, fertig. Die Felder für Adzuna- und Jooble-Keys kannst du leer lassen; die braucht nur die optionale eigene Suche.

💡 Nach dem Installieren Claude einmal neu starten, damit das Plugin geladen wird.

5

Loslegen

Jetzt kannst du Bob arbeiten lassen:

in Claude Code
/bob:bob-score

Dein Claude holt wartende Stellenanzeigen, wertet sie aus und bewertet sie gegen deine Profile. Die Ergebnisse erscheinen sofort in deinem Dashboard auf dieser Website.

Optional — eigene Jobs suchen: Wenn du kostenlose Keys von Adzuna und Jooble hinterlegst (per /plugin in der Bob-Konfiguration), suchst du mit /bob:bob-scan selbst neue Jobs und lieferst sie ein.

Wie Bob und dein Claude zusammenarbeiten

Damit du weißt, was passiert: dein Claude spricht über eine verschlüsselte Verbindung mit dem Bob-Server. Job-Rohtexte und deine Kriterien kommen zu dir, Bewertungen gehen zurück.

🔒 Dein Token authentifiziert jede Verbindung. Deine Bewertungen sind privat — andere Member sehen sie nicht.

🔒

Sicherheit — kurz & ehrlich

  • Dein API-Token ist persönlich. Nicht teilen, nicht in Code committen. Claude legt es sicher ab (Schlüsselbund bzw. Credentials-Datei), nicht in einem öffentlichen Repo.
  • Adzuna-/Jooble-Keys liegen im Klartext in deiner ~/.claude/settings.json — ein bewusster Kompromiss, damit die eigene Suche funktioniert. Es sind kostenlose Keys ohne Zugriff auf Bob-Daten; leg dort nichts Wertvolleres ab.
  • Alles ist einsehbar. Das komplette Plugin ist öffentlich lesbar: bob-member-kit ↗.
?

Wenn etwas klemmt

Fehler „401" / „Unauthorized" beim ersten Bob-Befehl

Das Token wird nicht erkannt. Erzeuge auf deiner Startseite ein neues Token (Schritt 3) und trag es per /plugin in der Bob-Konfiguration neu ein. Achte darauf, das komplette Token (bob_ + lange Zeichenfolge) ohne Leerzeichen einzufügen.

Die Befehle /bob:bob-score / /bob:bob-scan gibt es nicht

Das Plugin ist noch nicht geladen. Beende Claude Code und starte es neu. Prüfen kannst du es mit /plugin — dort muss bob als installiert erscheinen.

„Marketplace nicht gefunden" bei Schritt 4

Tippfehler im Befehl. Er lautet exakt /plugin marketplace add DJTJ9/bob-member-kit — am besten oben den Kopier-Button benutzen.

/bob:bob-scan sagt, es fehlen Keys

Die eigene Suche braucht kostenlose Keys von Adzuna und/oder Jooble. Trag sie per /plugin in der Bob-Konfiguration ein. Nur bewerten willst du? Dann brauchst du sie nicht — nutze einfach /bob:bob-score.

✓

Geschafft? So sieht Erfolg aus

  • ✅ /plugin install bob@bob-kit lief durch und fragte nach deinem Token.
  • ✅ /bob:bob-score startet ohne „401" und läuft durch.
  • ✅ In deinem Dashboard erscheinen bewertete Jobs.

Wenn alle drei Haken sitzen, bist du fertig — und jede Bewertung, die du fährst, macht die Treffer für alle Member besser. 🚀
